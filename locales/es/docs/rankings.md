# Vistas de ranking

Instantánea: `2026-11-27T10:03:03+00:00`. Es una ordenación por metadatos de mantenimiento, no una competición de capacidad de escritura. Todas las vistas agrupan primero por activo, inactivo desde hace tiempo, muy antiguo y archivado/histórico, y luego ordenan de forma descendente según el indicador de esa vista. En caso de empate se comparan las estrellas y el nombre del repositorio.
