# Vues de classement

Instantané : `2026-11-25T10:20:11+00:00`. Il s'agit d'un classement basé sur les métadonnées de maintenance, pas d'un concours de qualité d'écriture. Toutes les vues stratifient d'abord par actif, peu mis à jour depuis un moment, sans commit depuis très longtemps, archivé/historique, puis trient par ordre décroissant de l'indicateur de la vue. En cas d'égalité, on compare les étoiles puis le nom du dépôt.
