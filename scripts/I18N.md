# i18n layout

Every catalogue ships the same reading surface in five languages: English (default, repo root), Simplified Chinese, Spanish, Hindi and French (top five languages by total speakers).

## Output tree

| Path | Content |
| --- | --- |
| `README.md`, `docs/projects.md`, `docs/rankings.md`, `docs/<static>.md`, `CONTRIBUTING.md` | English (default) |
| `locales/<lang>/README.md`, `locales/<lang>/docs/projects.md`, `locales/<lang>/docs/rankings.md`, `locales/<lang>/docs/<static>.md`, `locales/<lang>/CONTRIBUTING.md` | one mirror per locale in `zh`, `es`, `hi`, `fr` |

Static prose in this catalogue: `docs/readme-intro.md`, `docs/taxonomy.md`, `docs/methodology.md`, `docs/research.md` and `CONTRIBUTING.md`.

`locales/<lang>` mirrors the root layout, so relative links inside a mirror (`docs/projects.md`, `CONTRIBUTING.md`) are written once in the templates. Generated files sit one level down in a mirror, so links they build into the repository root (`LICENSE`, `data/…`, `record/`) use the `{R}` prefix, computed by `prefix(locale,depth)`: at depth 0 (`README.md`) it is `""` in English and `"../../"` in a mirror; at depth 1 (`docs/rankings.md` pointing at `data/rankings.csv`) it is `"../"` in English and `"../../../"` in a mirror. No other placeholder name exists.

Hand-written prose resolves from its own directory, which is one level deeper, so the counts differ — `check_links()` enforces this:

| File | Link into repository root |
| --- | --- |
| `docs/research.md` (English) | `../research/search-log.json` |
| `locales/<lang>/docs/research.md` | `../../../research/search-log.json` |
| `docs/taxonomy.md`, `docs/methodology.md` (English) | `../data/…` |
| `locales/<lang>/docs/taxonomy.md`, `.../methodology.md` | `../../../data/…` |
| `CONTRIBUTING.md` (English) | `data/projects.json`, `record/` (paths in prose/code, not links) |

`docs/readme-intro.md` is the one prose file listed in `build.INLINE`: it is inlined into the README and therefore resolves from the locale root, writing `docs/projects.md` and `CONTRIBUTING.md` in both layouts.

Language switcher: the generated README of every locale starts with the same line linking all five, and ends with `records_note`, which points at `record/` and says the audit trail is not translated.

## Source of truth

| File | Role |
| --- | --- |
| `data/projects.json` | canonical review data, written in Chinese; also the fallback for `zh` |
| `data/seed-references.json` | user-reference seed mapping; data, not prose — never translated |
| `locales/<lang>/ui.json` | `language`, `language_name`, `list_separator` plus category, scope, licence-status, tier, mode labels, table headers, section titles and paragraph templates |
| `locales/<lang>/entries.json` | `repo → {description, form, boundary, license_label, license_note}` for that language, plus `name` when the canonical name contains Chinese (`evidence_notes` in the extraction source is not rendered and is dropped) |
| `locales/<lang>/docs/*.md`, `locales/<lang>/CONTRIBUTING.md` | hand-written static prose per locale |
| `locales/zh/ui.json` | the Chinese strings `build.py` used to hard-code; it is the translation source for every other locale |

`zh` has no `entries.json` — `build.py` falls back to `data/projects.json`. Every other locale must provide one entry per repository — `description`, `form`, `boundary`, `license_label`, `license_note` all non-empty — or `validate()` fails. The novel catalogue also renders `form` (形态, e.g. `桌面应用`, `Skill 包`) in the detail table and in every entry body, so the `form` column of `docs/projects.md` must be translated too.

Display names: seven canonical `name` values contain Chinese (e.g. `书童 Pagekin`, `易创 easy-writing`). For non-`zh` locales, `entries.json` must give those repos a `name` without Chinese; other repos may omit `name` and fall back to the canonical one. Tables, category overviews, entry headings and ranking views all render the locale name; `data/rankings.csv` keeps the canonical `p['name']`.

## Translation rules

- Keep facts identical to the Chinese source. Do not add claims, benchmarks or guarantees.
- Leave unchanged: repository names, project names, URLs, file paths, commit SHAs, license identifiers (MIT, AGPL-3.0, CC BY-NC-SA-4.0, FSL-1.1-ALv2 …), star counts, dates, model names, code blocks, Markdown table shape.
- Literal search keywords inside `docs/research.md` stay verbatim; only the surrounding prose and table headers are translated. That file is the one exception to the no-Chinese rule for non-`zh` locales, and `tests/test_i18n.py` enforces the narrow form of the exception: Chinese may appear only in Markdown table rows or inside backticks, never in prose lines.
- `record/` is an audit trail in the language it was written in; each locale links to it and says so (`records_note`).
