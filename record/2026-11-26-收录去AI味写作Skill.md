## 功能与边界要点

- `ste80-humanizer`：两遍改写——第一遍按 Wikipedia「Signs of AI writing」清单清掉 26 个机器味套路，第二遍按 ASD-STE100 重搭句子。README 明写目标是可读性、不是规避 AI 检测；「STE80」是「80% 靠拢」，因为完全符合 ASD-STE100 会把 `check`/`test` 只作名词、禁用 `may`/`should`，普通文章会失真。中文稿件效果需自行验证。
- `SimpleEnglish`：同一受控语言方向的写作 skill，默认通俗、按需严格，跨 Claude Code / Cursor / Codex / Gemini 等遵循 Agent Skills 标准的宿主。README 的 `−95%` 缺陷等数字来自作者自建 `evals/`，由 `evals/check_numbers.py` 在每次推送的 CI 里从已提交的 raw 文件复算——可复核，但仍是作者自评，不是第三方基准。用 `npx skills add` 只装 skill，不含 session hook 与 output style。
- 两者 `license_review.status = verified`、根 `LICENSE` 均为 MIT；规则清单引用的 Wikipedia 页面、ASD-STE100 规范文本与评测素材按各自来源条款另行核验。
