# 2026-11-05 AI 小说写作合集创建记录

目标仓库：https://github.com/ZanePoe/awesome_novel_writing

沿用 awesome_bot 的 GitHub 指标采集、维护分、分类生成与每日更新方式，建立 41 项 AI 小说及相关写作工具目录。13 个去重参考项目全部收录，ai-juben 已由用户确认对应 VanGong1999/juben。

分类为小说工作台、创作 Agent、长篇技能、修订检查、剧本解说及评测工具。新增发现包括 Oh Story、webnovel-writer、OpenFic、Denova、NovelClaw、Openwrite、Humanizer 系列和 Long-Novel-GPT 等。

功能与许可人工审核，star 和 30/90 天活动自动刷新。README、项目详表、四种排序视图及 CSV 可由 JSON 确定性生成。软件、Skill 和评测工具不做能力混排；尚未统一实机测评。

三轮调研记录、原始来源与首版快照见 [检索说明](../docs/research.md)。两组内容工厂近三个月查询成功返回空数组，不作为收录证据。

本地测试包含排序单调性、归档后置、默认分支时间、时区、同分稳定性、种子覆盖、部分 API 失败保留快照和 GraphQL 错误处理。GitHub 工作流配置为每日刷新，可手工触发验证。
